# Aviso de responsabilidade

Este projeto é fornecido para manutenção e configuração de sistemas Windows. Embora o foco seja usar operações conservadoras, **qualquer ferramenta executada com privilégios administrativos pode alterar o sistema**.

Use por sua conta e risco. Faça backup de arquivos importantes e leia o script antes da execução. O projeto não garante aumento de FPS, redução de latência ou melhoria mensurável em todo computador.
